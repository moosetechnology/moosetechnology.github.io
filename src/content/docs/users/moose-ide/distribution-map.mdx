---
title: 'Distribution Map'
---

Moose comes with the prebuilt Distribution Map visualization.
It has first been described in the paper [Distribution Map](https://www.researchgate.net/profile/Stephane-Ducasse/publication/221308136_Distribution_Map/links/02e7e51f0feed80eae000000/Distribution-Map.pdf).

One can find the Distribution Map under the Moose menu.
The browser is great to visualize a distribution of information across a system.
A typical usage consists in analyzing the system, and when you want to highlight a specific information, you create a tag that will be used to color the system.
Then, it is possible to open the visualization to investigate the distribution of this information across the system.

## Input

The Distribution Map takes as input a collection of container.
For instance, propagating classes will display classes as container and their methods and attributes as little square.
